# Project instructions

- Treat Polyphemus as a production Effect application.
- Decode unknown data at every Worker, Sandbox, process, model, file, identity, and persistence boundary.
- Keep Promise and platform adapters small; express application operations, failures, retries, and lifecycle with Effect.
- Never load repository-local Pi extensions, settings, skills, prompts, or context from cloned repositories.
- Never expose model or repository credentials in logs, result files, prompts, or user-visible events.
- Preserve the distinction between agent-reported claims and independently observed validation.
- Preserve `docs/sandbox-pi-feasibility-spike.md` as the historical feasibility record; use current product terminology in active code and documentation.
